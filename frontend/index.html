About BNIMS

The Bangladesh National ID Management System (BNIMS) is a database-driven application designed to maintain citizen identity information using a normalized relational database. This project demonstrates Database Management System (DBMS) concepts including relational schema, normalization, SQL queries, CRUD operations, and user interface design.

Centralized Database

Store citizen information in a secure relational database.

Secure Verification

Quick NID verification with secure identity validation.

Family Records

Maintain parent, spouse and family relationships efficiently.

System Modules

Citizen Information

Store NID number, full name, date of birth, gender, blood group and nationality.

Address Management

Present address, permanent address, division, district, upazila, postal code.

Family Information

Father, Mother, Spouse, Children, Guardian Information.

Verification

Search and verify National ID records instantly.

Administrative Panel

Manage users, reports, logs, database settings and permissions.

Reports

Generate reports, statistics, citizen summaries and verification history.
